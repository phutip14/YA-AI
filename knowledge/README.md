# 📚 CBTU YA AI Knowledge Base

โฟลเดอร์นี้ใช้สำหรับเก็บคลังความรู้ เอกสาร FAQ, SOP, ข้อมูลหลักสูตร และแนวทางการตอบของ CBTU YA AI 

### 📁 รูปแบบไฟล์ที่รองรับ:
- **Markdown (.md)**: เช่น cbtu_faq.md, sop.md, courses.md
- **Text (.txt)**: เอกสารข้อความทั่วไป
- **JSON (.json)**: เช่น qa.json, aq.json

### 💡 วิธีเพิ่มหรืออัปเดตความรู้:
1. สร้างหรือแก้ไขไฟล์ .md / .json ในโฟลเดอร์นี้
2. Commit & Push ขึ้น GitHub Repository
3. บอทจะดึงข้อมูลจากโฟลเดอร์นี้ไปประกอบเป็น Context ในการตอบคำถามของผู้ใช้โดยอัตโนมัติ
4. สามารถพิมพ์คำสั่ง /reload_knowledge ใน Discord เพื่อสั่งให้บอทรีโหลดคลังความรู้ใหม่ได้ทันที
